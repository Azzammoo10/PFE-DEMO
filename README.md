# Soutenance CSIRT React — version finale

## Lancer

```bash
npm install
npm run dev
```

Ouvrir : http://localhost:3000

## Navigation

- Flèche droite ou espace : slide suivante
- Flèche gauche : slide précédente
- `F` : plein écran
- `Home` : première slide
- `End` : dernière slide
